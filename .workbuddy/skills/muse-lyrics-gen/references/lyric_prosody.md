# 歌词的韵律语感设计

## 一、基础节奏框架：严格匹配 8 拍 / 组的和弦结构

对应「C 系列和弦 → Em 系列和弦」的沙发下行进行，固定为**两句一组、共 8 拍**的结构，每句音节数严格对应吉他拍点。

### 标准音节模板（单组 8 拍）

- **第 1 句（对应 C 和弦 4 拍）**：3~4 个音节，起句平缓、开口轻
  - 例：门虚掩着（4字/4拍）、空调滴水（4字/4拍）
- **第 2 句（对应 Em/B 和弦 4 拍）**：4~5 个音节，尾字落韵、语气下沉
  - 例：风掀了快递（5字/4拍）、数到第七滴（5字/4拍）

### 设计规则

1. **前短后长，贴合和声走向**：C 和弦句更短，Em/B 句稍长，对应低音从 C 到 B 半音下沉的"下坠感"
2. **永远不填满拍**：句尾留至少半拍气口，像日常说话一样自然断句
3. **单字均匀铺拍**：呢喃演唱时每个字匀速铺开，不做切分、不抢拍

## 二、韵脚设计：弱韵暗押，拒绝工整刻意感

沙发小曲的韵脚不能像传统民谣那样强押、句句押，否则会有"为了写歌词而写"的刻意感。

### 核心韵法：隔句暗押 + 宽韵收束

1. **优先闭口音韵部**：选 i / ü / ei 这类开口小的韵，气声好唱，自带慵懒氛围感
   - 推荐韵部：i 韵（滴、递、里、底、息）、ü 韵（雨、旅、去、续）、ei 韵（杯、灰、飞、睡）
2. **隔句落韵，不句句押**：仅每组 8 拍的第二句落韵
3. **允许近韵、半谐音**：读音接近即可，弱化"歌词感"

## 三、情绪设计：用细节藏情绪，拒绝外露

- **不写情绪词**：避免"难过""开心""孤独"等直接情绪表达
- **用细节替代**：用具体的场景、动作、物品暗示情绪状态
- **留白大于内容**：让听众自己感受，而不是被告知

### 示例对比

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 我感到很孤独 | 沙发陷着半边，没人发现我不在里面 |
| 心里很难过 | 杯底的圈，又淡了一圈 |
| 时间过得好慢 | 空调滴水，数到七 |

---

## 四、留白设计：气口与断句

### 气口位置

1. **句尾气口**：每句最后一个字只占半拍，剩下半拍留给吉他余韵
2. **句中停顿**：用逗号或空格表示自然呼吸
3. **段落留白**：Interlude 和 Outro 用"…"表示极轻的气声

### 断句原则

- 句子不超过 10 个字符
- 优先使用短句/碎片句
- 允许多行单字/双字短句

### 示例

```
沾着雨        （4字，轻柔）
数到七        （3字，留白）
…嗯…          （气声）
…没动…        （气声）
```

## 五、章节结构模板

### 标准沙发小曲结构

```
[Intro]      - 吉他纯分解，无歌词，4-8小节
[Verse 1]    - 主歌A，情绪铺垫，4组（8行）
[Verse 2]    - 主歌B，情绪微变，4组（8行）
[Interlude]  - 间奏，气声碎片，4小节
[Chorus]     - 副歌，场景串联，4组（8行）
[Verse 3]    - 主歌A'，回环感，4组（8行）
[Chorus]     - 副歌重复，情绪无变化
[Outro]      - 尾声，气声消散，6-8行
```

### 各章节特征

| 章节 | 人声 | 吉他 | 内容特征 |
|------|------|------|----------|
| Intro | 无 | 纯分解 | 余韵感 |
| Verse | 低呢喃 | 分解和弦 | 细节场景 |
| Interlude | 极轻气声 | 纯分解 | 碎片自语 |
| Chorus | 略舒展 | 扫弦轻柔 | 场景串联 |
| Outro | 渐弱至气声 | 泛音淡出 | 回神又沉回 |

## 六、禁止事项

1. ❌ 鼓组 / 重贝斯 / 电音
2. ❌ 副歌爆发 / 情绪高潮
3. ❌ 情绪词外露（难过、开心、孤独等）
4. ❌ 长复合句（超过10字）
5. ❌ 强押韵 / 句句押韵
6. ❌ 填满所有拍点
