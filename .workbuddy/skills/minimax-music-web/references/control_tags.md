# MiniMax Music 3 网页端 控制标签参考

本文档定义完整的段落控制标签体系，用于在 `[结构标签]` 后以 `[...]` 格式描述编曲、人声、情绪。

---

## 一、控制维度总览

| 维度 | 控制内容 | 标注方式 |
|------|----------|----------|
| **编曲** | 乐器、和弦、节奏型 | `[吉他分解...]` |
| **人声** | 音量、音区、唱法 | `[人声低输出呢喃]` |
| **情绪** | 情感基调、起伏 | `[情绪平静慵懒]` |
| **节奏** | 留白、断句、动态 | `[轻柔留白]` |
| **禁用** | 禁止元素 | `[无鼓组]` |

---

## 二、编曲控制

### 2.1 乐器标签

| 标签 | 含义 | 典型场景 |
|------|------|----------|
| `吉他分解和弦` | 指弹/拨弦分解 | Verse / Intro |
| `吉他扫弦` | 扫弦铺底 | Chorus |
| `木吉他单音泛音` | 空灵余韵 | Intro / Outro |
| `钢琴` | 钢琴铺底或点缀 | Chorus / Bridge |
| `氛围垫音` | 合成器垫底 | Interlude / Outro |
| `极淡氛围垫音` | 几乎听不见 | Intro |
| `弦乐轻柔揉入` | 弦乐组渐入 | Bridge / Chorus |
| `Bass轻拨` | 轻柔低音 | Verse |

### 2.2 和弦/指法标签

| 标签 | 含义 | 效果 |
|------|------|------|
| `Cadd9` | 挂留和弦 | 松弛悬置感 |
| `C7sus4` | 悬四和弦 | 悬而未决 |
| `Em9/B` | 转位和弦 | 色彩偏暗 |
| `Cmaj9` | 大九和弦 | 温暖 |
| `转位和弦` | 低音有变化 | 流动感 |
| `分解节奏型` | 节奏型分解 | 律动感 |
| `低音C→B半音滑动` | 沙发下行进行 | 下沉感 |

### 2.3 节奏/动态标签

| 标签 | 含义 | 使用场景 |
|------|------|----------|
| `轻柔留白` | 音符间留空 | 慵懒、民谣 |
| `极简节奏` | 节奏最少化 | 沙发小曲 |
| `四小节留白` | 纯器乐留白 | Interlude |
| `渐强但不爆发` | 微动态变化 | Pre-Chorus |
| `无高潮感` | 情绪平铺 | Chorus |
| `吉他缓慢淡出` | 动态渐弱 | Outro |

## 三、人声控制

### 3.1 音量/输出

| 标签 | 含义 | 典型场景 |
|------|------|----------|
| `人声低输出` | 音量压低 | Verse |
| `低声细语` | 几乎听不见 | Intro / Outro |
| `轻声呢喃` | murmur | Verse |
| `气声` | 带气息的声音 | Interlude |
| `极轻气声` | 若隐若现 | Outro |
| `极轻几乎听不清` | 气声极轻 | Interlude |

### 3.2 音区

| 标签 | 含义 | 效果 |
|------|------|------|
| `音区上移` | 音色偏亮 | Chorus（轻微） |
| `音区下移` | 音色偏暗/厚 | Verse 2 |
| `低音区` | 胸腔共鸣 | Verse |
| `中音区` | 自然音域 | Chorus |

### 3.3 唱法

| 标签 | 含义 |
|------|------|
| `无刻意情绪起伏` | 情绪平稳一致 |
| `略微舒展` | 轻微放开但克制 |
| `绝不爆发` | 禁止高潮爆发 |
| `情绪无变化` | 全程同一情绪 |
| `自言自语感` | 对着空气说 |
| `人声略微舒展` | 比 Verse 稍开放 |

## 四、情绪控制

### 4.1 情绪标签速查

| 情绪 | 强度 | 适用段落 |
|------|------|----------|
| `平静` | 中 | Verse |
| `慵懒` | 低 | 沙发标配 |
| `随性` | 低 | Lo-Fi |
| `放松` | 低 | Intro |
| `迷茫` | 中 | Verse |
| `内省` | 中 | 自我对话 |
| `疏离` | 中 | 冷淡人声 |
| `温暖` | 中低 | Chorus |
| `忧伤` | 中高 | Chorus |
| `慵懒随性` | 低 | Lo-Fi 核心 |
| `松弛疏离` | 中 | 城市孤独感 |
| `温暖内省` | 中 | 回忆感 |
| `平静迷茫` | 中 | 沙发小曲 |

## 五、段落控制模板

### 5.1 Intro（无歌词）

```
[Intro]
[吉他单音泛音余韵，极淡氛围垫音，无歌词，无鼓组]
```

### 5.2 Verse 1（主歌）

```
[Verse 1]
[吉他Cadd9到C7sus4分解节奏型，轻柔留白，人声低输出呢喃，音区中性，情绪平静慵懒，无鼓组]
歌词行1
歌词行2
...
```

### 5.3 Verse 2（主歌 - 氛围微暗）

```
[Verse 2]
[吉他Em9/B转位和弦为主，音区下移，氛围微暗，人声继续呢喃，情绪迷茫内省，无鼓组]
歌词行1
歌词行2
...
```

### 5.4 Pre-Chorus（预副歌 - 可选）

```
[Pre Chorus]
[吉他渐入，氛围微微上扬，人声略微舒展，为副歌铺垫，渐强但不爆发，无鼓组]
歌词行1
歌词行2
...
```

### 5.5 Chorus（副歌）

```
[Chorus]
[吉他扫弦轻柔铺开，Em11/B加Cmaj9色彩转换，人声略微舒展但绝不爆发，情绪无变化，无鼓组]
歌词行1
歌词行2
...
```

### 5.6 Chorus 重复

```
[Chorus]
[吉他指法同第一段，情绪无变化，保持松弛，无鼓组]
歌词行1
歌词行2
...
```

### 5.7 Interlude（间奏）

```
[Interlude]
[吉他纯分解和弦，四小节留白，人声气声极轻，几乎听不清，无鼓组]
…嗯…
…它没动…
...
```

### 5.8 Bridge（桥段）

```
[Bridge]
[吉他音色变化，引入新和声色彩，人声稍舒展，整体仍克制，无鼓组]
歌词行1
歌词行2
...
```

### 5.9 Outro（尾奏）

```
[Outro]
[吉他单音泛音缓慢淡出，氛围垫音渐隐，人声最后气声呢喃后安静，无鼓组]
…脚麻了…
…水很凉…
...

[Outro]
[吉他泛音余韵缓缓消散，最后仅剩淡淡空间感，安静收尾，无鼓组]
```

## 六、禁用标签（必加项）

| 标签 | 说明 | 适用场景 |
|------|------|----------|
| `无鼓组` | 禁止鼓组 | 沙发小曲必备 |
| `不允许鼓声` | 语气强调版 | 全部段落 |
| `无电音` | 禁止电子音色 | 慵懒/Lo-Fi |
| `无副歌爆发` | 不做高潮 | 沙发小曲 |
| `无重贝斯` | 低音轻柔 | 全部段落 |
| `无刻意情绪起伏` | 情绪平稳 | 全部段落 |

## 七、沙发小曲标准配置（快速参考）

```
[Intro]
[吉他分解和弦轻柔开场，木吉他单音泛音余韵，极淡氛围垫音，无歌词，不允许鼓声]

[Verse]
[吉他分解节奏型轻柔留白，人声低输出呢喃，情绪平静慵懒，音区中性，不允许鼓声]

[Chorus]
[吉他扫弦轻柔铺开，人声略微舒展但绝不爆发，情绪无变化，不允许鼓声]

[Interlude]
[吉他纯分解和弦，四小节留白，人声气声极轻，几乎听不清，不允许鼓声]

[Outro]
[吉他单音泛音缓慢淡出，氛围垫音渐隐，人声气声消散，不允许鼓声]
```
