## 区块优先级与可空性

| 区块 | 优先级 | 初始化时可空 |
|------|--------|------------|
| 元信息 | 最高 | 否 |
| 基础信息 | 高 | 是（无吉他时可不填） |
| 段落结构 | 高 | 否 |
| 多轨道规划 | 高 | 是（可在优化时补） |
| 和弦详情 | 高 | 是（无和弦时可不填） |
| 歌词 | 高 | 是（可在优化时补） |
| 旋律特征 | 中 | 是 |
| 附件与引用 | 中 | 是 |
| 工程日志 | 高 | 否（至少初始化记录） |
| 诊断与优化方向 | 中 | 是（诊断后生成） |

## 和弦记法规范

| 类型 | 记法 | 示例 |
|------|------|------|
| 基础和弦 | `根音 + 类型` | `C7` `Em7/B` `D#:maj7` |
| 进行 | `空格分隔 或 - 分隔` | `C7 Em7/B` 或 `C7 - Em7/B` |
| 指法 | 六位品格串 | `x 3 2 0 3 3` |
| 时间线 | `时间(秒) 和弦 置信度` | `0.00s  A:maj7  1.30` |

---

## 段落标签规范

| 类型 | 记法 | 示例 |
|------|------|------|
| 工程MD段落结构表 | 中文名+小节数 | `主歌A[8]` |
| 歌词标签 | 英文方括号 | `[Verse 1]` `[Chorus]` `[Intro]` `[Interlude]` `[Outro]` `[Bridge]` `[Pre-Chorus]` |
| 编曲注记（muse） | 圆括号 `()` | `(吉他分解和弦轻柔开场)` |
| 编曲注记（minimax） | 方括号 `[]` | `[吉他分解和弦轻柔开场]` |

## 产物 → 区块映射表

| 产物 | 产物路径 | 映射到工程MD区块 |
|------|---------|-----------------|
| 和弦方案 | `workspace/ai_chords/{歌名}/*.md` | 和弦详情 + 段落结构 |
| 歌词 | `workspace/muse_ai/{歌名}/lyrics/lyrics.md` | 歌词 |
| 歌词设计 | `workspace/muse_ai/{歌名}/lyrics/lyrics.design.md` | 元信息 + 歌词【全局设定】 |
| audio report | `workspace/audio_output/{歌名}/report.md` | 旋律特征 + 和弦时间线 + 附件引用 |
| 分轨wav | `workspace/audio_output/{歌名}/tracks/` | 附件与引用 |
| MIDI | `workspace/audio_output/{歌名}/melody/melody.mid` | 附件与引用 |
| minimax歌词/风格 | `workspace/minimax_music_v3/{歌名}/` | 参考/不内嵌（格式特殊） |
| 已有雏形 | `workspace/project/{歌名}/project.md` | 升级合并 |

## 字段名规范（消除歧义）

| 旧名（不统一） | 规范名 | 说明 |
|-------------|--------|------|
| 形态 / 风格 | 风格 | 统一用"风格" |
| 弹法 / 编配方式 | 弹法 | 统一用"弹法" |
| 段落结构（箭头链字符串） | 结构串 | 段落结构区块内的单行摘要 |
| 段落结构（表格） | 段落结构表 | 段落结构区块内的表格 |

## 注释符号规范

| 符号 | 用途 |
|------|------|
| `> {文字}` | 歌曲一句话定位，放在标题后 |
| `---` | 区块内子节分隔（如歌词段落间） |
| `#### 标题` | 四级标题用于段落详情 |
| `*斜体文字*` | 技能签名（由 xxx 生成） |
| `\`代码\`` | 行内代码，和弦/指法/标签 |
| ``` ``` ``` | 代码块，和弦进行/把位速查/和弦时间线 |
