| 标签 | 说明 | 使用场景 |
|-----|------|---------|

## 标签组合使用

可以组合多个标签获得更精细的控制：

```
[Verse 1](柔和钢琴伴奏, Male Vocal, 情感叙述)
[Pre-Chorus](渐强, 制造张力)
[Chorus](Fortissimo, 全乐队, 情感爆发)
[Bridge](仅钢琴, 情感沉淀)
```

## 注意事项

1. 标签放在段落开头或歌词中需要的位置
2. 可同时使用多个标签，用逗号分隔
3. 中文和英文标签可以混用
4. 标签不影响歌词内容本身，仅影响音乐和演唱风格
