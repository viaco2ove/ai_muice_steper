# Muse AI 歌曲结构模板集

## 1. 流行歌曲模板 (最常见)

适合：华语流行、英文流行、抖音神曲

```
[Intro]
[Verse 1]
(主歌1 - 叙事铺垫，4行)
(叙述故事开场，交代背景)
(旋律相对克制，为副歌做铺垫)

[Pre-Chorus]
(预副歌 - 情绪抬升，2-4行)
(建立张力，引导进入高潮)
(可重复部分句子增强期待感)

[Chorus]
(副歌 - 记忆点核心，4-8行)
(最想被记住的句子)
(短句重复，易于传唱)
(情感爆发点)

[Verse 2]
(主歌2 - 故事发展，4行)
(推进情节，增加细节)
(与主歌1不同内容)

[Pre-Chorus]
(预副歌2 - 再次铺垫)

[Chorus]
(副歌重复)

[Bridge]
(桥段 - 转折变化，2-4行)
(换视角或减弱配器)
(为最后一次副歌做铺垫)

[Chorus]
(最终副歌 - 可加长或变奏)

[Outro]
(尾奏 - 收束情绪)
(可重复副歌主题句)
```

## 2. 民谣歌曲模板

适合：民谣弹唱、校园歌曲、情感慢歌

```
[Intro](原声吉他)
[Verse 1]
(主歌 - 叙事为主，4行)
(简单旋律，木吉他伴奏)
(讲述故事或场景)

[Chorus]
(副歌 - 情感抒发，4行)
(主题句出现)
(可加入和声)

[Verse 2]
(主歌2 - 情节推进)

[Chorus]
(副歌重复)

[Verse 3]
(主歌3 - 深化主题)
(可选，视歌曲长度)

[Chorus]
(副歌重复)

[Bridge]
(桥段 - 情绪转折)
(可转调或改变配器)

[Chorus]
(最终副歌)

[Outro](吉他渐弱)
(尾奏留白)
```

## 3. 电子舞曲模板 (EDM)

适合：电音、舞曲、健身音乐、夜店风格

```
[Intro](电子音效渐入)
[Verse 1]
(主歌 - 建立基础节奏)
(相对克制，铺垫为主)

[Build-Up]
(能量堆叠 - 逐渐增强)
(加入合成器层次)
(为Drop做铺垫)

[Chorus/Drop]
(爆发段 - 能量最大)
(强劲节拍)
(短句重复，记忆点强)

[Break]
(分解段 - 能量降低)
(只保留核心元素)
(制造对比)

[Build-Up]
(再次堆叠)

[Chorus/Drop]
(第二次爆发)

[Breakdown]
(再次降低)

[Build-Up]
(最终堆叠)

[Chorus/Drop]
(最终爆发)

[Outro](电子音效渐出)
```

## 4. 说唱/嘻哈模板

适合：说唱、Trap、Hip-Hop

```
[Intro](节拍铺垫)
[Verse 1]
(主歌1 - 说唱段落，8-16行)
(快节奏歌词)
(押韵设计)

[Hook/Chorus]
(记忆点 - 短句重复)
(通常是副歌Hook)
(可唱可说)

[Verse 2]
(主歌2 - 继续叙事)

[Hook/Chorus]
(副歌重复)

[Verse 3]
(主歌3 - 故事高潮或转折)

[Hook/Chorus]
(副歌重复)

[Bridge](可选)
(变奏或过渡)

[Hook/Chorus]
(最终副歌)

[Outro](节拍渐弱)
```

## 5. 情歌/告白歌曲模板

适合：爱情歌曲、告白、甜蜜氛围

```
[Intro](钢琴或吉他轻柔)
[Verse 1]
(主歌 - 遇见你之前)
(描写心境或场景)

[Pre-Chorus]
(预副歌 - 心动的瞬间)
(情感升温)

[Chorus]
(副歌 - 告白核心)
(直接表达情感)
(甜蜜温暖)

[Verse 2]
(主歌 - 和你在一起的时光)
(细节描写)

[Pre-Chorus]
(预副歌)

[Chorus]
(副歌重复)

[Bridge]
(桥段 - 情感深化)
(可加入誓言或承诺)

[Chorus]
(最终副歌 - 可加入和声)

[Outro]
(尾奏 - 甜蜜收尾)
(重复主题句)
```
