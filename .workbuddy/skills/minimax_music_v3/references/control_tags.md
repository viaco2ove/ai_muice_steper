# MiniMax Music 3 段落控制标签参考

## 编曲说明标签体系

### 乐器控制

| 标签 | 含义 | 示例 |
|------|------|------|
| `吉他分解和弦` | 指弹/拨弦分解 | `吉他分解和弦轻柔铺开` |
| `吉他扫弦` | 扫弦伴奏 | `吉他扫弦铺底` |
| `钢琴` | 钢琴铺底 | `钢琴单音点缀` |
| `氛围垫音` | 氛围合成器垫底 | `极淡氛围垫音` |
| `弦乐` | 弦乐组 | `弦乐轻柔揉入` |
| `Bass` | 低音 | `Bass轻拨铺底` |

### 和弦/指法

| 标签 | 含义 |
|------|------|
| `Cadd9` | 挂留和弦，松弛感 |
| `C7sus4` | 悬四和弦，悬而未决 |
| `Em9/B` | 转位和弦，色彩偏暗 |
| `Cmaj9` | 大九和弦，温暖 |
| `转位和弦` | 低音有变化 |
| `分解节奏型` | 节奏型分解 |

### 节奏控制

| 标签 | 含义 | 使用场景 |
|------|------|----------|
| `轻柔留白` | 音符间留空 | 慵懒、民谣 |
| `极简节奏` | 节奏最少化 | 沙发小曲 |
| `四小节留白` | 纯器乐留白 | Interlude |
| `无鼓组` | 禁止鼓组 | 必加 |
| `无重贝斯` | 禁止重低音 | 可选 |

---

## 人声控制标签

### 音量/输出

| 标签 | 含义 |
|------|------|
| `人声低输出` | 音量压低 |
| `轻声细语` | 几乎听不见 |
| `呢喃` | murmur |
| `气声` | 带气息的声音 |
| `极轻气声` | 若隐若现 |

### 音区

| 标签 | 含义 |
|------|------|
| `音区上移` | 音色偏亮 |
| `音区下移` | 音色偏暗/厚 |
| `中音区` | 自然音域 |
| `低音呢喃` | 胸腔共鸣 |

### 情绪表达

| 标签 | 含义 |
|------|------|
| `无刻意情绪起伏` | 情绪平稳 |
| `略微舒展` | 轻微放开但克制 |
| `绝不爆发` | 禁止高潮 |
| `情绪无变化` | 全程同一情绪 |

---

## 情绪控制标签

### 正面情绪

| 标签 | 强度 | 示例 |
|------|------|------|
| `平静` | 中 | 沙发主歌 |
| `放松` | 低 | Intro |
| `温暖` | 中低 | Chorus |
| `愉悦` | 中高 | Bridge |

### 负面/中性情绪

| 标签 | 强度 | 示例 |
|------|------|------|
| `慵懒` | 低 | 沙发标配 |
| `迷茫` | 中 | Verse |
| `疏离` | 中 | 冷淡人声 |
| `内省` | 中 | 自我对话 |
| `忧伤` | 中高 | 副歌 |

### 混合/复杂情绪

| 标签 | 说明 |
|------|------|
| `慵懒随性` | Lo-Fi 核心 |
| `松弛疏离` | 城市孤独感 |
| `温暖内省` | 回忆感 |
| `平静迷茫` | 沙发小曲标配 |

## 段落控制模板

### Intro

```
[Intro]
[吉他单音泛音余韵，极淡氛围垫音，无歌词，无鼓组]
```

### Verse

```
[Verse 1]
[吉他分解和弦轻柔留白，人声低输出呢喃，音区中性，情绪平静，无鼓组]
歌词行1
歌词行2
...

[Verse 2]
[吉他Em9/B转位和弦，音区下移氛围微暗，人声继续呢喃，无鼓组]
歌词行1
歌词行2
...
```

### Pre-Chorus（可选）

```
[Pre Chorus]
[吉他渐入，氛围微微上扬，人声略微舒展，为副歌铺垫，无爆发，无鼓组]
歌词行1
歌词行2
...
```

### Chorus

```
[Chorus]
[吉他扫弦铺开，和弦色彩转换，人声略微舒展但绝不爆发，情绪保持克制，无鼓组]
歌词行1
歌词行2
...

[Chorus]
[吉他指法同第一段，情绪无变化，保持松弛，无鼓组]
歌词行1
歌词行2
...
```

### Interlude

```
[Interlude]
[吉他纯分解和弦，四小节留白，人声气声极轻，几乎听不清，无鼓组]
…嗯…
…它没动…
...

[Interlude]
[氛围垫音微微浮现，吉他低音轻拨，脚步般的节奏，无鼓组]
```

### Bridge

```
[Bridge]
[吉他音色变化，引入新和声色彩，人声稍舒展，但整体仍克制，无鼓组]
歌词行1
歌词行2
...
```

### Outro

```
[Outro]
[吉他单音泛音缓慢淡出，氛围垫音渐隐，人声最后气声呢喃后安静，无鼓组]
…脚麻了…
…水很凉…
...

[Outro]
[吉他泛音余韵缓缓消散，最后仅剩淡淡空间感，安静收尾，无鼓组]
```

## 禁用标签（必加）

| 标签 | 说明 |
|------|------|
| `无鼓组` | 沙发小曲必备 |
| `无电音` | 禁止电子音色 |
| `无副歌爆发` | 不做高潮 |
| `无重贝斯` | 低音轻柔 |
| `不允许鼓声` | 语气强调版 |

---

## 快速参考：沙发小曲标准配置

```
[Intro]
[吉他分解和弦开场，极淡氛围垫音，无歌词，无鼓组]

[Verse]
[吉他分解节奏型轻柔留白，人声低输出呢喃，情绪平静慵懒，无鼓组]

[Chorus]
[吉他扫弦轻柔铺开，人声略微舒展但绝不爆发，情绪无变化，无鼓组]

[Interlude]
[吉他纯分解和弦，四小节留白，人声气声极轻，无鼓组]

[Outro]
[吉他单音泛音缓慢淡出，氛围垫音渐隐，人声气声消散，无鼓组]
```
