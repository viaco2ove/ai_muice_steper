# ai_chords_master — 沙发小曲编曲与创作技能

## 触发词
写和弦、和弦进行、沙发小曲、沙发进行、丰富和弦、编曲、设计段落、和弦走向

## 核心功能

基于用户给定的**基础和弦** + **哼唱旋律**，生成：

1. **丰富化和弦进行** — 在基础形态上叠加色彩和弦、转位、延伸音
2. **段落结构设计** — 前奏、主歌、副歌、间奏、尾奏的完整规划
3. **旋律构思** — 基于识别到的旋律音，给出音符走向、情绪落点建议

/ai_chords_master

## 基础信息

用户在弹奏前会说明吉他夹几品，这决定了**实际音高**与**弹奏指法**的关系：

```
Capo = N  →  实际音高 = 编配音高 + N 半音
例: Capo=3, 编配=C  →  实际弹 Eb 大调
```

技能需要记录以下基础信息（无 capo 时 capo=0）：

| 字段 | 说明 | 示例 |
|------|------|------|
| capo | 夹几品 | 3（三品）|
| capo_key | 编配在哪个调 | C（C大调）|
| actual_key | 实际弹出的调（自动计算） | Eb |

**用户在对话中给出 capo 信息时，必须在编曲方案中明确标注出来，作为基础信息的一部分。**

## 工作流程

```
Step 1: 解析基础和弦进行
Step 2: 识别核心和声骨架（C7=属七主，Em7/B=小七下属）
Step 3: 设计丰富和弦（转位、挂留、色彩替代）
Step 4: 生成完整段落结构
Step 5: 结合旋律走向优化和弦落点
Step 6: 输出完整编曲方案（含吉他指法建议）
```

## 和弦丰富化原则

### 核心骨架（C7 + Em7/B）保留
- C7 的属七张力 → 可以延迟解决（慵懒感来源），不改
- Em7/B 的低音 B → 半音下行锚点，必须保留

### 丰富方向

#### A. 色彩和弦注入（在保持骨架的前提下插入）
| 位置 | 候选和弦 | 效果 |
|------|---------|------|
| C7 前 | Cmaj9、Cadd9 | 更柔和的主调氛围 |
| C7 内部 | C9、C13、C7sus4 | 属七的慵懒感保留，增加厚度 |
| Em7/B 内部 | Em9、Bm7b5（N.C.） | 小七和弦的悬浮感加强 |
| Em7 后 | E7sus4、E7alt | 在回到 C7 前积累微紧张 |
| 间奏/过渡 | Am9、Fmaj9、Gm7 | 关系的 IV-VII 级，提供呼吸感 |

#### B. 转位优化（低音线条更流动）
- Em7/B → Em11/B（低音仍是 B，上方多一个 A）
- C7 → C7/E（C 的根音保持，E 作为中间音）

#### C. 挂留和弦（减速感）
- 在每个小节第 3 拍插入 sus4，4 拍落回原和弦
- 例: `C7 C7sus4 C7 | Em7/B Em7sus4 Em7/B`

#### D. 爵士色彩（沙发绽二级延伸）
- C7 → Cmaj7（减少张力，更放松）
- Em7/B → Em11 → Bm9（更迷蒙的过渡）

### 禁止事项
- 不使用大横按强力和弦（破坏沙发场景感）
- 不加入增和弦或减七和弦（过于戏剧化）
- 不使用快速的 II-V-I 进行（节奏太快，不慵懒）
- 延伸形态中不使用失真音色、强鼓点

## 段落设计模板（沙发小曲标准）

### 形态 A：纯沙发核（基础形态）
```
前奏    [4小节]  纯吉他沙发进行
主歌 A  [8小节]  人声进入，基础和弦
主歌 B  [8小节]  歌词递进，和弦略丰富
间奏    [4小节]  吉他独奏/旋律加花
主歌 A' [8小节]  歌词反复或微调
尾奏    [4小节]  和弦弱化 → 停在 Em7 泛音
```

### 形态 B：沙发绽（延伸形态）
```
前奏    [4小节]  沙发核质感（纯吉他）
主歌    [8小节]  人声+吉他，基础形态
预副歌  [4小节]  极弱加入第一件乐器（贝斯低音/沙锤）
副歌    [8小节]  全部延伸乐器进入，情绪舒展
间奏    [4小节]  乐器 Solo（吉他/口琴）
主歌+副歌反复
尾奏    [4小节]  乐器逐层褪去 → 纯吉他 → Em7 泛音
```

## 旋律构思

### 核心旋律线（基于你的哼唱）
- 音域: G2 ~ B3（低音区，适合慵懒演唱）
- 旋律特点: [A音为主，稳定巡航；偶有 G# 下滑，制造呼吸感]
- 情绪落点: [第 3 句落在 A#3，情绪微微上扬]

### 各段落旋律建议
- 前奏: 从 G3 缓慢下行到 G2，模拟"坐下"的感觉
- 主歌 A: 以 A3 为轴心，偶向 G3 或 A#3 延伸
- 副歌: 可尝试到达 B3，但不超过，保持整体慵懒
- 尾奏: 旋律逐渐下行，最后停在 G2 长音

## 吉他编法建议

### 主歌指法
```
Cmaj9:  x 3 2 0 3 0   (低音 x, GCEAD)
C7:     x 3 2 3 3 0   (3323x 改良版)
Em11/B: x 2 4 4 3 0   (0243x 转位)
Em7/B:  0 2 4 3 0 0   (开放式，B 为根音)
```

### 右手技法
- 拇指低音 + 三指分解，节奏平缓
- 每拍均匀，可带极轻微 shuffle 但不摇摆
- BPM: 68，全曲匀速

---

## 延伸建议（若升级到沙发绽）
- L1 轻绽: 加入沙锤（每小节第 2、4 拍轻点）
- L2 舒展: 加入 upright bass（拨弦，弱拍进入）
- L3 漫放: 加入轻柔的电钢琴和声垫音
