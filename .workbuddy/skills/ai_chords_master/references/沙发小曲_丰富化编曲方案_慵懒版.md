# ai_chords_master 使用指南

## 基本用法

### 方式一：CLI 一键生成
```bash
# 基础版（沙发核）
python .workbuddy/skills/ai_chords_master/scripts/full_composition.py \
    --progression "C7,C7,Em7/B,Em7/B,Em7" \
    --title "我的沙发曲"

# 完整版（配合音频分析）
python .workbuddy/skills/ai_chords_master/scripts/full_composition.py \
    --audio "标准录音 1.mp3" \
    --progression "C7,C7,Em7/B,Em7/B,Em7" \
    --title "我的沙发曲" \
    --form bloom \
    --tempo 65

# 仅丰富和弦进行（不生成段落）
python .workbuddy/skills/ai_chords_master/scripts/composer.py \
    --progression "C7,C7,Em7/B,Em7/B,Em7" \
    --enrichment "full" \
    --output chord_progression.md
```

### 方式二：直接对话触发
在 WorkBuddy 中直接说：
- "帮我基于 C7 C7 | Em7/B Em7/B | C7 C7 | Em7/B Em7/B | Em7 写一个沙发小曲的和弦进行"
- "这个和弦走向可以怎么丰富"
- "设计一个慵懒风格的完整编曲方案"

---

## 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--progression` | 基础和弦进行，逗号分隔 | 必填 |
| `--audio` | 音频文件路径（用于旋律分析） | 可选 |
| `--title` | 歌曲名 | "沙发小曲" |
| `--form` | `standard`（沙发核）或 `bloom`（沙发绽） | standard |
| `--enrichment` | `light`/`rich`/`full` 丰富程度 | rich |
| `--tempo` | BPM | 68 |
| `-o, --output` | 输出文件 | 自动命名 |

## 和弦丰富化规则

### 原始骨架
```
C7 → C7 → Em7/B → Em7/B → C7 → C7 → Em7/B → Em7/B → Em7
```

### 丰富化策略
1. **小节开头**：用 Cmaj9 / Cadd9 / C7sus4 替代 C7，降低张力
2. **小节中间**：保持 C7 或用 C9 增加厚度
3. **小节结尾**：用 C13 或 Cmaj7 收束感
4. **转位优化**：Em7/B → Em9/B（保留低音 B）
5. **挂留减速**：每小节第 3 拍插入 sus4，4 拍落回

### 禁止事项
- ❌ 增和弦 / 减七和弦（过于戏剧化）
- ❌ 大横按强力和弦
- ❌ 快速 II-V-I 进行
- ❌ 失真音色 / 强鼓点

## 段落结构参考

### 沙发核（standard）
```
前奏[4小节] → 主歌A[8小节] → 主歌B[8小节] → 间奏[4小节] → 主歌A'[8小节] → 尾奏[4小节]
```

### 沙发绽（bloom）
```
前奏[4小节] → 主歌[8小节] → 预副歌[4小节] → 副歌[8小节] → 间奏[4小节] → 主歌+副歌[8小节] → 尾奏[4小节]
```

## 与 audio_chord_recognizer 配合

1. **先用** `/audio_chord_recognizer @你的录音.mp3` **分析旋律**
2. **再告诉 ai_chords_master**：
   ```
   基础和弦: C7 C7 | Em7/B Em7/B | C7 C7 | Em7/B Em7/B | Em7
   风格: 沙发小曲
   旋律: [描述或直接 @同一音频]
   ```
3. 系统会结合音频分析结果自动优化和弦落点
