# Prompt Writing Guide for MiniMax Music API

## Prompt Structure

```
A [mood] [BPM optional] [genre] song, featuring [vocal description],
about [narrative/theme], [atmosphere], [key instruments and production].
```

Example:
```
A melancholic 68 BPM lo-fi song, featuring soft whispered female vocals,
about late night wandering, intimate bedroom atmosphere, acoustic guitar
and subtle ambient pads.
```

## Genre Keywords

| Genre | Keywords |
|-------|----------|
| Lo-Fi | lo-fi, chillhop, lo-fi hip hop, couch, sofa |
| Folk | indie folk, acoustic, folk ballad |
| Ambient | ambient, atmospheric, dreamy, ethereal |
| Jazz | jazz, bossa nova, smooth jazz, saxophone |
| Electronic | synthwave, ambient electronic, downtempo |
| Classical | piano solo, classical guitar, orchestral |

## Mood Keywords

| Mood | Keywords |
|------|----------|
| Peaceful | calm, serene, tranquil, peaceful |
| Melancholic | melancholic, nostalgic, wistful, bittersweet |
| Energetic | upbeat, energetic, lively, vibrant |
| Dark | dark, moody, haunting, somber |
| Romantic | romantic, tender, intimate, loving |

## Vocal Descriptions

| Type | Description |
|------|-------------|
| Soft | soft female voice, gentle, breathy |
| Deep | deep male voice, baritone, warm |
| Whispers | whispered vocals, intimate, close-mic |
| Choir | choir vocals, harmonies, ethereal |
| None | instrumental only, no vocals |

## Instrument Keywords

| Category | Instruments |
|----------|-------------|
| Strings | acoustic guitar, electric guitar, violin, cello |
| Keys | piano, Rhodes piano, electric piano, synthesizer |
| Wind | saxophone, trumpet, flute |
| Percussion | drums, shaker, tambourine, handclaps |
| Ambient | pad, drone, texture, field recordings |

## BPM Reference

| Feel | BPM Range | Example |
|------|-----------|---------|
| Very slow | 50-65 | Ballads, ambient |
| Slow | 65-80 | Lo-fi, folk |
| Medium | 80-100 | Pop, R&B |
| Upbeat | 100-120 | Dance, rock |
| Fast | 120+ | High energy |

## Production Tags

| Tag | Effect |
|-----|--------|
| lo-fi | Vinyl crackle, tape hiss, degraded |
| warm | Analog warmth, tube saturation |
| intimate | Close-mic, small room sound |
| spacious | Reverb, delay, wide stereo |
| minimalist | Sparse arrangement, lots of space |

## Tips

1. **English prompts** work best - translate Chinese style descriptions
2. **Be specific** about instruments and mood
3. **Mix genres** creatively (e.g., "lo-fi bossa nova")
4. **Reference artists** if helpful (e.g., "like Mac DeMarco")
5. **Avoid** cramming too many adjectives - focus on 3-4 key descriptors
