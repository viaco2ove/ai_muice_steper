# 沙发小曲（Sofa Tune）风格体系完整定义
这是一种以「居家松弛感」为核心精神的当代城市民谣分支，以纯吉他人声的基础形态为根，以「先沉聚、后舒展」为内在能量逻辑，衍生出可轻可重、可简可繁的开放风格谱系。

---

## 一、风格核心精神与双形态架构
沙发小曲的本质不是"慢歌"，而是**「居家状态下的情绪呼吸」**——它对应现代人窝在沙发里的两种状态：先是卸下防备、沉入柔软的松弛，再是在松弛中慢慢回血、生出想要做点什么的轻量兴致。

由此形成两个严格递进的形态：
- **基础形态 · 沙发核（Sofa Core）**：纯吉他+人声，零额外乐器。全程慵懒、平缓、向内收，功能是"放松与沉聚能量"。
- **延伸形态 · 沙发绽（Sofa Bloom）**：在沙发核的能量基底上自然舒展，逐步融入其他乐器与乐风元素，功能是"能量的温和释放"。

**核心规则**：延伸形态永远不能脱离"沙发场景感"，不可以出现强烈的鼓组、失真音色、炸裂的高音，所有加入的元素都必须像"从沙发旁随手拿起一件乐器"一样自然。

## 二、基础形态 · 沙发核（Sofa Core）
### 1. 标志性和声：「沙发下行进行」
你给出的 `C7 → C7 → Em7/B → Em7/B → C7 → C7 → Em7/B → Em7/B → Em7` 是这个风格的基因级进行，可正式命名为**沙发下行进行（Sofa Descent）**。

#### 和声逻辑解析
- **低音半音下沉**：C7 的低音 C → Em7/B 的低音 B，半音级的缓慢下行，自带"身体陷进沙发"的下坠感与松弛感。
- **和弦色彩悬停**：属七和弦 C7 本有向 F 解决的倾向，但这里不解决，反而转向关系小和弦 Em7/B，形成一种"不紧张、也不释放"的悬浮感，正是慵懒的核心来源。
- **结尾落于 Em7**：最终收束在柔和的小三和弦上，像一次深长的呼气，完成一轮能量的沉聚。

#### 变体规则（基础形态内）
- 可移调，但必须保留**「属七 → 转位小七」的半音低音下行**结构，例如 D7 → Bm7/A、G7 → Em7/D。
- 可偶尔插入 Am7、Dm7 等过渡和弦，但占比不能超过 20%，全程以沙发进行为主干。
- 禁止使用大横按强力和弦、禁止快速离调、禁止终止式强收。

### 2. 吉他编法典范
- **音色**：木吉他原声，琴箱共鸣感强，轻微打品与手指摩擦声可保留，增加"居家随手弹"的真实感；禁止加效果器。
- **右手技法**：以拇指根音+三指分解为主，节奏平缓，每拍均匀，可带极轻微的 shuffle 律动但不可摇摆；扫弦仅限极轻的空心扫，音量弱于分解。
- **速度**：BPM 60–75，全程匀速，无明显渐快渐强。
- **低音处理**：刻意强调 C → B 的半音低音线条，用拇指稍重拨响，这是整个风格的"松弛锚点"。

### 3. 演唱规范
- **发声方式**：气声占比 40% 以上，真声为主，不用混声、不用高音嘶吼，音域控制在 8 度以内。
- **咬字状态**：像自言自语、像对着空气哼唱，咬字松弛不发力，尾音可轻轻带过，不必字正腔圆。
- **歌词主题**：日常碎片、发呆思绪、微小情绪、天气与光线，不写宏大叙事、不写激烈爱恨。
- **气息逻辑**：每句结尾留空，像呼吸一样自然，不追求填满每一拍。

### 4. 能量机制：松弛不是涣散
沙发核的"慵懒"≠ 萎靡，它的内在逻辑是**「被动放松 → 主动沉聚」**。
- 前半段：卸下外界压力，纯放松，情绪向下沉。
- 后半段：在重复的和弦循环中，情绪慢慢稳定，能量悄然积聚，为延伸形态做铺垫。
- 整首基础形态作品结束时，听者应感到"平静、踏实、有点想站起来做点什么"，而不是"更困了"。

## 三、延伸形态 · 沙发绽（Sofa Bloom）
### 1. 演化原则
延伸形态是基础形态能量积聚后的**自然舒展**，不是另起炉灶。它必须遵守三条铁则：
1. **吉他核心不变**：原声吉他始终是伴奏主干，其他乐器只做填充与点缀，不能盖过吉他。
2. **场景不脱离**：所有声音都要符合"在客厅沙发旁能实现"的听觉想象，拒绝音乐厅、夜店、体育场质感。
3. **能量温和释放**：可以更明快、更有律动，但不能亢奋、不能炸，最高能量级别止于"心情很好地在沙发上晃脚"。

### 2. 三级延伸体系
按能量释放程度，分为三个层级，创作时可逐级递进，也可只取某一层。

#### 一级延伸 · 轻绽（Light Bloom）
最接近基础形态，仅加入极弱的环境化音色。
- 可加入乐器：卡洪鼓（仅指尖轻拍）、沙锤、手指打板、极轻的贝斯拨弦。
- 律动变化：节奏略微清晰，但 BPM 提升不超过 10。
- 适用场景：午后阳光、看书、慢节奏家务。

#### 二级延伸 · 舒展（Full Bloom）
融入明确的风格元素，是沙发小曲最具辨识度的延伸态。
- 推荐融合乐风：
  - **巴萨诺瓦**：加入轻量 bossa 节奏型，吉他略带反拍，慵懒中带一丝微甜。
  - **冷爵士**：加入九和弦色彩，偶尔插入爵士分解乐句，松弛中带高级感。
  - **城市民谣**：加入口琴、轻量口风琴，叙事感增强。
- 可加入乐器：upright bass（原声贝斯）、口琴、颤音琴、轻量电钢琴（音色偏暖）。
- 能量感：像在沙发上坐直了身体，开始轻轻跟着晃。

#### 三级延伸 · 漫放（Free Bloom）
能量释放的边界，再往前就脱离沙发小曲范畴。
- 可融合方向：轻量 Neo-Soul、低保真卧室流行、法式香颂、轻电子（仅低保真鼓机+氛围音色）。
- 可加入乐器：柔和的合成器垫音、鼓机（仅 808 弱音色）、轻柔的和声伴唱。
- 红线：绝对禁止强鼓点、失真吉他、重型贝斯、高音炫技。
- 能量感：像从沙发上站起来，在客厅里慢慢踱步、轻轻跳舞。

### 3. 乐器加入的"沙发原则"
- **随手原则**：想象这件乐器能不能放在沙发旁边、随手就能拿起来演奏。能，则符合；不能（比如架子鼓），则不符合。
- **不抢话原则**：所有加入的乐器都像"陪衬的朋友"，吉他与人声永远是主角。
- **留白原则**：乐器越少越好，宁可空着，也不要填满。

## 四、标准曲式结构
### 基础形态标准结构（单段循环式）
> 前奏（4小节，纯吉他演奏沙发进行）
> → 主歌 A（8小节）
> → 主歌 B（8小节，歌词递进，演唱极轻微加强）
> → 间奏（4小节，纯吉他，可加入一点点旋律加花）
> → 主歌 A'（8小节，歌词反复或微调）
> → 尾奏（4–8小节，和弦慢慢弱化，最后停在 Em7 泛音上，像慢慢睡着）

### 延伸形态标准结构（渐进舒展式）
> 前奏：纯吉他沙发进行（沙发核质感）
> → 主歌：吉他+人声，基础形态质感
> → 预副歌：极弱地加入第一件乐器（如沙锤、贝斯低音），能量开始抬升
> → 副歌：全部延伸乐器进入，情绪舒展但不爆发
> → 间奏：乐器solo小段（吉他或口琴等）
> → 主歌+副歌反复
> → 尾奏：乐器逐层褪去，最后回到纯吉他，收束回沙发核质感
> *（形成「从沙发出发→舒展→回到沙发」的闭环）*

## 五、创作示例（基础形态片段）
**调号：C大调 / BPM：68 / 拍号：4/4**
**和弦进行：C7 C7 | Em7/B Em7/B | C7 C7 | Em7/B Em7/B | Em7**

```
  C7                Em7/B
台灯晕开了 傍晚的光
  C7                Em7/B     Em7
沙发陷进去 半个肩膀

  C7                Em7/B
手机扔在 不远的地方
  C7                Em7/B     Em7
今天的事 明天再讲
```

演唱提示：每句最后一个字轻轻收掉气声，"光""膀""方""讲"都带一点尾音的虚化，像叹气一样自然。

## 六、风格美学主张
沙发小曲的内核，是当代都市人对「无目的舒适」的需求。它不追求感动人、不追求炸裂、不追求技巧，只提供一段"可以什么都不想的时间"。

- 慵懒不是颓废，是主动选择的慢下来。
- 松弛不是涣散，是为了更好地积聚能量。
- 简单不是简陋，是剔除所有不必要的东西后，留下最舒服的部分。
