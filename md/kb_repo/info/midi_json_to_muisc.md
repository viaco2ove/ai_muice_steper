# 完整MIDI → 带真人质感人声+分轨WAV 最优工具分层方案
按你的工作流需求：**已有固定多轨MIDI、可迭代修改乐谱、自动化批量、分轨独立输出人声/乐器干声**，分本地可控管线（首选）、云端方案、轻量快速方案三类，附带优缺点适配你的沙发小曲吉他编曲。

## 一、本地可控方案（最推荐，匹配你的JSON/MIDI全流程）
### 1. ACE Studio（国产中文人声天花板，完美适配）
#### 核心能力
1. 直接导入人声单轨MIDI + 对应歌词，AI生成纯净无伴奏人声音频干声WAV；
2. 支持批量API调用，Python脚本自动化渲染，和你的FluidSynth乐器管线打通；
3. 可精细调节气声、颤音、滑音、推弦参数，解决AI人声机械感，适配沙发小曲慵懒人声；
4. 人声轨道可单独导出，不和吉他/鼓混合，后期自由混音；
5. 海量中文歌手模型，民谣、治愈温柔声线匹配你的曲风。
#### 配套流程
1. 拆分多轨MIDI：人声轨道单独导出`vocal.mid`，乐器轨道`guitar.mid/drum.mid`；
2. ACE加载`vocal.mid+歌词`，输出纯人声干声wav；
3. FluidSynth + FluidR3 GM 渲染全部乐器分轨wav；
4. Python+FFmpeg自动合并所有分轨，输出成品MP3。
#### 优势
100%锁定你MIDI里的旋律、节奏，AI只优化人声质感，不会擅自改旋律；支持批量自动化，无RPM限流，一次付费永久本地使用。

### 2. Synthesizer V Studio 2 Pro（多语言人声，备选）
适合需要英文/小众民谣演唱，原理和ACE一致：MIDI驱动生成干声人声，本地批量渲染，缺点中文咬字自然度略弱于ACE。

### 3. 乐器渲染：FluidSynth（你正在用，免费开源）
搭配FluidR3_GM音色库渲染吉他、贝斯、鼓、合唱垫分轨WAV；想要极致吉他质感可以叠加Ample Sound吉他插件（DAW内手动精修）。

### 4. DAW（Studio One / FL Studio）精修收尾
把ACE人声干声 + FluidSynth乐器分轨导入DAW，添加EQ、混响、压缩，精细混音后导出最终分轨/成品WAV；适合单曲精调，批量自动化用Python管线绕过DAW。

## 二、云端API方案（MiniMax / Suno，有硬缺陷）
### MiniMax music-3.0
1. 限制：**无法直接上传MIDI**，只能上传MIDI渲染后的参考WAV，AI会轻微改动旋律、和弦，不能严格锁定你写好的吉他solo线条；
2. 产出：只能导出混合分轨音频（人声/乐器分离wav），**无法反向输出可编辑MIDI**，迭代修改必须回到本地原始MIDI；
3. 适用场景：仅定稿后升级整体编曲质感，不适合迭代制作。

### Suno V5
支持上传MIDI作为旋律约束，AI自动配器+生成人声；同样无法导出可编辑MIDI，分轨音频可用，但中文人声自然度不如ACE。
### 云端通用短板
受RPM限流（免费版3次/分钟）、消耗大量token、网络依赖，批量自动化稳定性远不如本地工具。

## 三、免费轻量极简方案（预算有限，临时预览）
1. SynthV免费基础版：少量中文歌手，MIDI生成人声干声，音质够用；
2. FluidSynth开源免费渲染乐器；
短板：歌手数量少，缺少气声等高级调节，长期商用质感不足。

  推荐路径（按你"精确控制人声"的需求）

  路径 A：虚拟歌手编辑器（最精准）⭐⭐⭐

  Synthesizer V / ACE Studio / CeVIO

  工作流：
  1. 把 02_主唱.json 的逐字音名+时值+拍位 转成 MIDI（你已有 export_track_to_midi.py）
  2. 导入 SynthV Studio（用免费基础版 + 付费中文歌手如"五维" / "赤羽" / "苍穹"）
  3. 选男歌手，调整 vibrato / portamento / 气声参数
  4. 渲染干声 wav

  优点：逐字逐音精确、可控制气声比例、可加 vibrato/portamento、可调音准
  缺点：要付费（歌手 $30-100）+ 学习曲线

  路径 B：开源歌声合成（免费但需 GPU）⭐⭐

  DiffSinger (https://github.com/Moetanjo/diffsinger)
  - 输入：MIDI + 歌词
  - 输出：歌声 wav
  - 中文模型：opentt/fastspeech 等已有中文歌手
  - 6GB 显存可跑

  工作流：
  # 1. 导出主唱 MIDI
  python export_track_to_midi.py --track 02_主唱

  # 2. 转成 DiffSinger 输入格式（ds 项目的 utils/midi2ds.py）
  python utils/midi2ds.py 02_主唱.mid 02_主唱.ds --lyrics 歌词.txt

  # 3. 推理
  python inference/main.py --config 配置.yaml

  路径 C：minimax music-cover（最省力）⭐⭐

  用你的半成品 WAV 当参考音频

  # 1. 先调用 preprocess
  curl https://api.minimaxi.com/v1/music_cover_preprocess \
    -F audio=@full_multitrack_fs.wav

  # 返回 cover_feature_id

  # 2. 再生成翻唱版（强制遵循参考音频的音高节奏）
  curl https://api.minimaxi.com/v1/music_generation \
    -d '{"model":"music-cover-free","cover_feature_id":"...","lyrics":"..."}'

  优点：免费 RPM 3、强制参考音频
  缺点：仍然整曲输出，但人声会贴你半成品的节奏

## 五、最终落地最优流程（你的完整管线）
1. 本地脚本拆分多轨MIDI：人声、吉他分解、吉他solo、鼓、合唱垫单独分文件；
2. 人声声轨：ACE Studio API读取人声MIDI+歌词，导出纯净人声干声WAV；
3. 乐器轨道：FluidSynth加载FluidR3_GM音色，批量渲染吉他、鼓、合唱垫独立WAV；
4. （可选）导入Studio One做精细混音，调节人声、吉他音量层次，保证主旋律突出；
5. FFmpeg合并所有分轨，输出成品320kbps MP3。

## 六、避坑要点
1. 不要只用云端工具做主流程：会丢失MIDI可迭代编辑能力，AI擅自改动你精心设计的五声legato/布鲁斯吉他solo；
2. 人声和乐器**必须分轨渲染**，不要一次性混缩，方便后续修改旋律重新渲染单轨；
3. 预览优先用本地管线，云端仅作为定稿后的质感升级补充。
