  推荐三条路径

  路径 A：OpenUTAU（完全免费，今天就能跑）⭐⭐⭐

  OpenUTAU 是开源虚拟歌手编辑器，免费版能渲染出 80% SynthV 效果。

  # 1. 下载 OpenUTAU
  # https://openutau.com/  (Windows/Mac/Linux)

  # 2. 下载中文歌手
  # 比如 "GPT-SoVITS 训练的中文男歌手" / "MUTA 试听版" / "青溯" 等
  # OpenUTAU 内置 "声库市场" 一键下载

  工作流：
  1. 把 02_主唱.mid 导出（用你已有的 export_track_to_midi.py）
  2. 打开 OpenUTAU → 导入 MIDI → 输歌词（直接粘贴 lyrics.md 内容）
  3. 选中文男歌手 → 调整 Pitch/Tension/Vibrato
  4. 点 Render → 输出 wav

  优点：
  - ✅ 完全免费，无限首歌
  - ✅ 逐字逐音精确控制（每个音的音高、时长、力度都可调）
  - ✅ 内置中文歌手数十个（男/女/童声）
  - ✅ 支持 vibrato/portamento 滑音曲线编辑
  - ✅ 输出 24bit/48kHz 干声 WAV

  缺点：
  - ⚠️ 渲染速度慢（CPU 渲染一首 3 分钟要 5-10 分钟）
  - ⚠️ 比付费 SynthV 真人感略弱

  路径 B：Synthesizer V Studio（$60，效果最好）⭐⭐⭐⭐⭐

  付费但效果最好。

  推荐中文男歌手（匹配你的 Lo-Fi 慵懒需求）：
  - 五维 Wennie - Lo-Fi 风，$70
  - 苍穹 - 慵懒男声，$50
  - Merlin - 英文但能唱中文，$60

  工作流：
  1. 买 SynthV Studio 基础版（免费试用版支持 1 首歌！） → https://synthesizerv.com/
  2. 试用版先试效果，满意再买歌手
  3. 同 OpenUTAU 工作流

  优点：
  - ✅ 业界最真人感的歌声合成
  - ✅ 试用版免费 1 首歌
  - ✅ 中文支持好

  缺点：
  - ❌ 基础版 $60 + 歌手 $50-100

  如果你有 RTX 3060 以上的显卡，DiffSinger 本地推理。

  # 1. 克隆
  git clone https://github.com/openvpi/DiffSinger.git
  cd DiffSinger

  # 2. 安装
  pip install -r requirements.txt

  # 3. 下载中文预训练模型
  # https://github.com/yyggg-max/diffsinger-models  (中文男歌手模型)
