# 转音完整设计指南（人声可唱性+AI适配+风格区分）
转音本质：两个骨干音之间，用**级进/小跳装饰音**平滑衔接，消除生硬断层；对应OpenUtau里手动绘制PITD音高曲线，解决DiffSinger机械断裂。
先分三类基础转音：滑音级进转音、装饰花腔转音、切分顿挫转音，再讲可唱性、风格、AI调音实操。

## 一、三类基础转音结构（旋律写法）
### 1. 平滑线性滑转（二度级进，最通用）
核心：两个音之间填满连续二度邻音，无跳跃
示例：3 → 5 中间填充 4，写成3 4 5；下行5 4 3
1. 可唱性：满分，真人唱丝滑，AI无需复杂曲线，轻微PITD即可自然
2. 气质：温柔、抒情、叙事、伤感，华语慢歌、古风主歌标配
3. 使用场景：长音衔接、句尾拖腔、低音过渡高音

### 2. 小跳回旋转音（3-4度来回环绕）
骨干音上下3度小跳往返，形成波浪转音
示例：5 3 5、6 4 6
1. 可唱性：中等，不能密集堆叠；连续回旋真人容易挤嗓
2. 气质：灵动、婉转、国风戏腔、甜系流行R&B
3. 限制：一段乐句最多1处回旋，多了杂乱

### 3. 半音装饰转音（半音滑音，R&B/蓝调专用）
插入半音小二度，1→#1→2、5→b5→6，自带慵懒氛围感
1. 可唱性偏低，普通人难把控，AI很容易失真刺耳
2. 气质：慵懒、慵懒R&B、复古抒情、都市情歌

### 4. 大跳缓冲转音（解决5度以上大跳断层关键手法）
规则：**大跳之后反向级进转音回填**
上行5度跳1→5，立刻下行级进5 4 3；
下行大跳6→2，立刻上行级进2 3 4。
作用：符合人声生理，消除割裂，是你写旋律必须遵守的规则。

## 二、按段落分配转音密度（避免杂乱）
1. 主歌：少转音，仅句尾短滑转，以平稳级进叙事
2. 预副歌：少量回旋转音，逐步抬升情绪
3. 副歌记忆点：1处标志性长转音（歌曲记忆点）
4. 桥段/高潮：适度密集花转音，情绪顶峰
5. 尾句拖腔：长线慢速滑转，弱化收尾

## 三、不同风格专属转音模板
### 1. 华语抒情慢歌（最稳妥，AI渲染最稳定）
- 转音结构：长音线性下行/上行级进滑音
- 节奏：慢均分八分音符，拖腔拉长
- 搭配：长转音叠加BREC气息曲线，增加气声弱化机械
例：句尾长音5，转音5 4 3 2缓慢回落

### 2. 古风/戏腔
- 核心：3度回旋转音+下行级进拖腔
- 特点：句尾多来回环绕转音，婉转悠扬
- 避坑：不要加半音转音，会破坏国风调性

### 3. R&B流行、甜歌
- 核心：半音装饰短转音、切分节奏转音
- 节奏：十六分音符快速小花转，轻短点缀
- 气质灵动；不可整句铺满，会杂乱

### 4. 摇滚、力量型歌曲
少细碎转音，只用**长距离慢速滑转**；拒绝密集小花腔，否则削弱爆发力

## 四、转音节奏设计（决定高级感，90人只关注音高忽略节奏）
1. 慢转音（八分/四分音符）：抒情、氛围感，适配长音拖腔
2. 快花转音（十六分音符三连音）：灵动高光段落，只用于高潮点缀
3. 切分转音：转音落在弱拍，制造慵懒松弛感（R&B核心）
4. 禁止：全曲统一均等快速转音，听觉疲劳、AI密集音符易渲染过载

## 五、适配OpenUtau DiffSinger 转音调音实操（解决机械断层）
### 1. 线性级进转音（最简单）
旋律本身写连续二度音，PITD曲线平缓直线，几乎不用手动调整，渲染稳定，极少报GRU错误。

### 2. 大跳缓冲转音（必做）
旋律已经按规则反向回填级进；额外操作：
在两个大跳音符之间画**平缓弧形PITD曲线**，缓慢过渡，消除AI硬切断层。

### 3. 快速小花腔回旋转音
1. 音符拆分细一点，不要一个音符硬跳；
2. PITD曲线画柔和波浪，避免直角折线；
3. TENC张力轻微降低，防止快速转音尖锐刺耳；
4. 不要一次性写4小节以上密集转音，分段工程防止USTX数据过载崩溃。

### 4. 半音蓝调转音注意
半音极易出现AI失真、破音，TENC全程压低，搭配轻微DYN音量衰减。

## 六、新手设计转音避坑
1. 连续多处大跳，无反向级回填：人声割裂，AI断层严重
2. 全程铺满密集十六分花转音：杂乱无记忆点，渲染负载暴涨
3. 大跨度快速半音转音：难听、尖锐、极易渲染失败
4. 转音全部直角硬转折，不用平滑曲线：机械感翻倍
5. 主歌大量花哨转音，掩盖主旋律记忆点

## 七、万能转音写作流程
1. 先写骨干主旋律（只用级进、小跳，无复杂装饰）
2. 在句尾、副歌高点，选择性添加转音装饰
3. 大跳段落强制加反向级进缓冲转音
4. 根据风格选定转音类型（线性滑/回旋/半音）
5. 控制节奏密度，慢歌长滑、快歌短花
