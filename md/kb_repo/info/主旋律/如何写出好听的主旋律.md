# 零基础写好听主旋律完整教程（适配AI唱歌DiffSinger，兼顾顺口、好唱、不机械）
## 一、先定基础框架（决定好不好听的底层逻辑）
### 1. 选调式（流行歌优先）
1. **自然大调（明亮、治愈、甜歌）**：C/G/F大调，适合轻快、温柔流行
2. **自然小调（伤感、抒情、氛围感）**：Am/Em/Dm，情歌、慢歌首选
3. 避开和声小调、旋律小调新手难驾驭，容易难听、唱着别扭

### 2. 拍号&速度
- 抒情慢歌：4/4拍，65–85BPM
- 轻快流行：4/4拍，90–120BPM
绝大多数中文歌都是4/4，不建议新手用3/8、6/8

### 3. 乐句结构（黄金四句体，听众最容易记住）
标准段落：**起-承-转-合**（8小节一句，4句一段共32小节）
1. 起（1–8小节）：抛出核心动机，最简单的一句旋律
2. 承（9–16小节）：重复动机，轻微改动，巩固记忆点
3. 转（17–24小节）：音域拉高/走向反转，制造情绪起伏（副歌高潮）
4. 合（25–32小节）：回到开头旋律收尾，形成闭环

## 二、旋律写作黄金规则（避免难听、AI唱着生硬断层）
### 1. 音域控制（适配人声，AI不会刺耳）
普通人声舒适区间：**低音C3 ~ 高音F4**
- 副歌最高音不要连续长音堆高音，容易尖锐、渲染崩溃
- 高低音不要频繁大跳（超过6度），AI转音会断层、机械感暴增
> 正确：级进（相邻1/2度）+ 小跳（3–4度）为主，偶尔5度跳跃提亮情绪

### 2. 音高走向公式（万能好听走向）
1. 温柔抒情：**下行为主**，缓慢往下走，伤感氛围感拉满
2. 轻快甜歌：**上下起伏小波浪**，短音来回浮动
3. 高潮副歌：先上行推高情绪，再缓慢下行回落
禁止：全程直线往上/直线往下，毫无起伏，听感像念经

### 3. 节奏搭配（解决人声呆板）
1. 长短音结合，不要全是均分八分音符（最机械）
   - 长音（二分/四分）放重拍，承载情绪；
   - 短音（十六分、八分）做装饰，增加灵动；
2. 重拍放高音、长音，弱拍短音过渡；
3. 句尾统一拉长音，给BREC气息曲线留出调整空间，AI人声更自然。

### 4. 重复变化法则（抓耳洗脑）
好听的旋律一定有重复，单纯全新音符会很乱：
1. 动机重复：第一句核心2–4个音符，第二句原样复刻；
2. 模进重复：整体升高/降低2–3度重复动机（流行最常用）；
3. 变奏重复：旋律骨架不变，只改末尾1–2个音符，不单调又统一。

## 三、和声搭配（旋律好听的核心支撑）
新手万能和弦走向，直接套旋律：
1. 温柔抒情小调（Am）：Am - F - C - G
2. 治愈大调（C）：C - G - Am - F
3. 伤感副歌：Em - C - G - D
4. 轻快甜歌：C - Am - F - G
小技巧：旋律音尽量落在和弦内部音（根音、三音、五音），经过音快速带过，不会刺耳跑调。

## 四、适配你OpenUtau DiffSinger的专属技巧（减少机械、渲染报错）
1. 乐句不要超过8小节，长句拆分两段，避免ustx参数过载GRU崩溃；
2. 大跨度跳跃音符手动画PITD滑音曲线，抹平断层；
3. 长音预留出来拉BREC气息，提升自然度；
4. 不要连续4个以上超高音，TENC张力曲线不好补救，还容易渲染失败。

## 五、从零实操步骤（直接上手写）
1. 定速度、调式、4句8小节结构；
2. 写2–4个音符的核心小动机（歌曲记忆点）；
3. 重复+模进写出前两句；
4. 第三句上行拉高音域做高潮；
5. 第四句回落动机收尾；
6. 搭配和弦，调整长短音节奏；
7. 导出MIDI导入OpenUtau，新建干净工程填歌词；
8. 绘制BREC/TENC/PITD曲线弱化机械感。

## 六、新手避坑（写出来难听的常见问题）
1. 频繁7/8/9度大跳，人声割裂刺耳；
2. 全曲音符长短完全一致，节奏无变化；
3. 音域过高，全程顶高音；
4. 乐句没有重复，音符杂乱无记忆点；



# 旋律如何发展，主要有哪些方向
# 旋律发展的核心手法（通用流行/古风，适配你做AI人声）
旋律发展=把一句简短动机（2~4个音的核心短句）进行变形、延展，让整首歌有逻辑、不单调，分为**重复类、对比类、延伸变形类**三大方向。

## 一、重复类（最基础、最抓耳，新手优先用）
核心：保留原动机骨架，听众容易记住，歌曲洗脑
1. **完全重复**
原句原样再演奏一遍，强化记忆点。
例：主歌第一句旋律，第二句一模一样。
适用：主歌铺垫、副歌记忆段。
缺点：连续多次完全重复会乏味，一般最多重复2次就要变化。

2. **变化重复（同头换尾）**
开头音符、节奏不变，只改动最后1~2个音。
最常用发展手法，统一又有新意。
例：第一句123 5-，第二句123 2-。

3. **同尾换头**
结尾落音、节奏不变，开头音改变，情绪轻微递进。

4. **移位重复（模进，流行/古风高频）**
把完整动机整体向上/向下平移若干音，节奏完全不变，音高统一升降。
- 上行模进：情绪上扬、推向副歌高潮；
- 下行模进：情绪低落、伤感抒情。
细分：
- 严格模进：音程距离完全一致；
- 自由模进：大致平移，微调个别音适配和弦，更好听。

## 二、对比类（制造起伏、转折，用来做“转句/高潮”）
前面重复铺垫后，用对比打破平淡，制造歌曲起伏，对应四句体里的「转」段落。
1. **音域对比**
前面旋律偏低，发展段整体拉高音域，形成高潮；
或前面高音，段落回落低音，营造压抑、温柔氛围。

2. **走向对比**
原动机整体下行，发展段改成上行波浪；
原平缓起伏，发展段做大跨度跳跃。

3. **节奏对比**
短句短音 → 长音拖腔；
均分八分音符 → 切分、附点节奏，瞬间改变氛围。

4. **调式/和声对比**
大调段落临时转入小调色彩，或更换和弦色彩，旋律情绪同步变化。

## 三、延伸变形类（不破坏动机，拉长、拆分、装饰）
不改变核心轮廓，只是拉长、拆解、装饰原有动机，适合乐句内部细化。
1. **扩充（拉长）**
原短句很短，在中间加经过音、延长尾音，把2小节动机扩成4小节。
多用于抒情慢歌，拉长气息，AI演唱更自然。

2. **压缩（缩减）**
4小节动机压缩成2小节短句，节奏变紧凑，适合副歌推进。

3. **分裂（拆分动机）**
把完整动机拆成零散小片段，穿插停顿，制造留白。

4. **加花装饰**
原有骨干音不变，中间插入滑音、辅助音、半音过渡，丰富细节；
放到OpenUtau里就是手绘PITD滑音曲线，弱化机械断层。

5. **倒影（反向）**
以某一个音为中心，原动机向上跳的地方改为向下跳，走向完全镜像。
例：原动机135，倒影531；适合氛围感、古风歌曲。

6. **逆行**
把动机音符顺序倒过来演奏，1235 → 5321，小众但独特。

## 四、收束类（合句，段落结尾收尾）
段落最后一句发展手法，用来闭环旋律：
1. **回归开头动机**
高潮过后，回到开篇原始旋律，形成首尾呼应，结构完整；
2. **落音收拢**
所有乐句统一落在主音/属音，稳定收尾，不会飘；
3. **渐慢拉长尾音**
句尾加长音，给气声、颤音留出调节空间，适配DiffSinger人声。

# 实用搭配模板（写歌直接套用）
## 模板1：温柔抒情慢歌（四句起承转合）
1. 起：简短动机（2小节）
2. 承：同头换尾变化重复
3. 转：上行模进+拉高音域对比，推向高潮
4. 合：回归开头动机，长音收束

## 模板2：轻快流行甜歌
1. 起：短节奏动机
2. 承：下移模进重复
3. 转：节奏加密、小音域对比
4. 合：完全重复记忆点收尾

## 模板3：伤感古风
1. 起：下行短句
2. 承：自由模进下行
3. 转：倒影+上行高音制造情绪爆发
4. 合：回落低音，长音拖腔收尾

# 适配你OpenUtau DiffSinger的额外要点
1. 模进、加花产生的音高跳跃，一定要画PITD滑音，避免AI演唱断层生硬；
2. 扩充出来的长音，搭配BREC气息曲线，提升自然度；
3. 不要一次性过度大量倒影、逆行，旋律过于复杂容易渲染报错；


# 平进，级进，跃进，模进，旋律的可唱性和风格性
# 级进、平进、跳进、模进 完整区分 + 可唱性 + 风格适配
## 一、四个基础概念（音程定义）
1. **平进（同音反复）**
同一个音重复，音程=纯一度
例：5 5 5 | 3 3
2. **级进（邻音走动）**
相邻音阶，半音/全音，二度音程
上行级进：1234；下行级进：5432
3. **跳进（大跳）**
三度及以上间隔，分小跳（3–4度）、大跳（5度及以上）
小跳：13、25；大跳：15、37、16
4. **模进（移位重复）**
把一段完整旋律片段，整体统一升高/降低固定音程，节奏完全不变
分上行模进、下行模进、严格模进、自由模进

## 二、各自可唱性（人声/AI DiffSinger 演唱难度）
### 1. 平进｜极易演唱，零难度
- 人声：最省力，不用换音高，大白歌、童谣大量使用
- AI表现：几乎无断层，不用画PITD滑音；缺点是单调机械
- 短板：全程平进会像念经，必须搭配少量级进打破呆板

### 2. 级进｜最佳可唱性，人声最自然
- 人声：声带平稳过渡，换气顺滑，流行抒情、慢歌核心写法
- AI优势：无音高断层，不用手动修滑音，渲染稳定，极少出现GRU报错
- 唯一缺点：纯级进缺少记忆点，情绪起伏偏弱，不够抓耳

### 3. 跳进（分小跳/大跳）
#### 小跳（3–4度）：可唱性良好
人声轻松切换，流行副歌通用；AI轻微画一点滑音就顺滑。
#### 大跳（≥5度）：可唱性差
- 真人：高音低音来回切换，费嗓子，容易跑调
- AI缺陷：天然断层、割裂感极强，机械感暴增；
  必须手绘长段PITD平滑曲线，否则渲染出来两段声音断开，甚至增大张量触发GRU崩溃
- 通用规则：**大跳之后必须反向级进回填**（往上跳很高，立刻往下走级进，符合人声呼吸逻辑）

### 4. 模进｜可唱性看内部构成
- 模进内部以级进、小跳为主：超好唱，流畅洗脑（华语流行副歌标配）
- 模进包含连续大跳：极难唱，AI生硬刺耳，不适合中文抒情歌
长段连续模进会让音符密度暴涨，存入USTX容易参数过载渲染失败，建议8小节内截断。

## 三、四种写法对应的风格气质
### 1. 平进（同音重复）
气质：平缓、诉说、平淡、叙事感
适配风格：民谣、叙事主歌、说唱式旋律、治愈轻音乐
慎用：全程副歌大量平进，容易乏味、催眠

### 2. 级进（二度邻音）
气质：柔和、细腻、伤感、温柔、流动
适配风格：抒情慢歌、古风、情歌主歌、纯治愈流行
特点：氛围感强，适合铺垫情绪，适合搭配气声BREC曲线提升自然度

### 3. 跳进
1）小跳（3/4度）
气质：灵动、轻快、微微上扬，自带记忆点
适配：甜系流行、轻摇滚副歌、日系抒情
2）大跳（5度及以上）
气质：反差、爆发、撕裂、戏剧冲突、恢弘
适配：古风戏腔、史诗、摇滚高潮、伤感爆发段
⚠️ 限制：中文流行很少连续大跳，容易违和；国风歌曲单次五度跳最稳妥

### 4. 模进（整体移位）
1）上行模进：层层推高、情绪递进、高潮蓄力
适用：副歌前预副歌、歌曲升情绪段落（华语流行最常用）
2）下行模进：低落、压抑、悲凉、释然
适用：伤感情歌、古风悲歌、结尾收束句
3）连续多段模进：洗脑、抓耳，记忆点极强；过量会流水线网红歌质感

## 四、黄金搭配公式（兼顾好听+好唱+降低AI机械感）
1. 温柔主歌模板（高可唱，自然不机械）
**级进为主 + 少量同音平进 + 偶尔3度小跳**
全程无大跳，AI渲染稳定，气息顺滑。

2. 流行副歌记忆点模板（抓耳，难度适中）
短句上行模进（内部级进+小跳），搭配单次5度大跳，大跳后立刻下行级进回填，平衡冲突感。

3. 古风伤感模板
下行级进+下行自由模进，句尾同音平进拉长拖腔，适配长音气声。

4. 避雷组合（难听+AI极度生硬）
连续7度/8度大跳、全程纯平进、无回填的孤立大跳、长段含大跳的连续模进。
