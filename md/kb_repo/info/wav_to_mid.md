# 人声 WAV 转 MIDI 乱码
# 人声WAV转MIDI乱码、杂音的完整原因（分「底层原理」「你的音频问题」「工具垃圾」三类）
## 一、根本底层矛盾（不是工具单方面的锅，天生硬伤）
WAV是**连续波形录音**（记录所有细微颤音、滑音、气声、泛音、混响、呼吸）；
MIDI是**离散音符指令**（只有「音高+起止时间」，只认规整方块音符）。
1. 人声没有纯标准音符：唱歌全程是连续滑音、颤、转音，CREPE这类逐帧音高追踪会每十几毫秒生成一个不同音高，转换后变成密密麻麻碎音符，听起来像乱弹噪音（你CSV里几千行零散midi=-1/56/57就是证据）。
2. 人声自带杂信号：呼吸、齿音、泛音、混响尾、伴奏残留，算法会全部识别成临时音符，堆一堆无效短音。
3. 单音限制：转换算法只适合**单声部干净干声（无伴奏、无和声、无混响）**，只要有叠加声音直接崩。

## 二、你用的在线工具audio-convert是重度垃圾（核心人为问题）
1. 算法老旧：只用基础FFT傅里叶变换，无AI音高清洗、无音符合并、无八度过滤，不会过滤呼吸/泛音碎音，人声处理能力几乎为0，钢琴都转不好，人声直接报废。
2. 无预处理功能：不能降噪、不能切除混响、不能限定音域、不能设置最小音符时长，细碎音全部保留。
3. 算力/模型阉割：免费在线工具不会搭载pYIN、CREPE、Basic Pitch这类专业音高模型，识别精度极低。
4. 线下普通转换工具同理：免费桌面转换器大多和它同源，效果一样烂。

## 三、你的人声素材本身4个致命问题（90%人踩坑）
1. **带伴奏/和声**
整首歌曲混合WAV，鼓、贝斯、和声、乐器频率与人声叠加，算法分不清主旋律，多频率全部生成音符，彻底混乱。
解决：先用UVR5/Moises提取**纯人声干声（无伴奏、无和声）**再转。
2. 人声混响/延迟太重
录音加了大混响，尾音泛音持续震荡，每一段残响都会被识别成音符，多出几百条碎音。
解决：DAW里先消除混响，导出干声再转换。
3. 噪音、呼吸、齿音多
换气、嘶嘶齿音、底噪会被判定为低频/中频音符，出现一堆无关杂音音符。
解决：降噪、修剪空白呼吸段。
4. 音量过载/过小
波形削波（爆音）会扭曲音高；音量太低识别偏移，大量错音。

## 四、正确解决方案（分免费/专业，彻底解决乱码）
### 方案1：免费可用（网页，Basic Pitch Spotify官方模型，远胜你那个网站）
工具：Basic Pitch（spotify开源网页）
优势：内置AI合并长音、过滤泛音碎音、自动修剪短杂音，专门优化单声部人声，输出干净MIDI。
操作：
1. UVR5分离纯人声干声；
2. 降噪、消混响；
3. 上传Basic Pitch导出MIDI；
4. 导入MuseScore/FL删掉残留碎音符。

### 方案2：专业DAW插件（精度天花板，Melodyne / Logic Flex Pitch）
行业人声转MIDI标准，基于pYIN/CREPE精准音高追踪，自带音符合并、颤音平滑，导出MIDI几乎无碎音。
流程：干净人声导入 → 音高检测 → 手动修正滑音边界 → Transfer导出MIDI。

### 方案3：本地开源（CREPE/pYIN脚本，对应你那份csv音高文件）
你手里的pitch.csv就是CREPE逐帧音高表，不要直接丢在线工具；
写简单脚本**合并连续相同midi数值**，过滤时长<50ms的碎音，再导出标准MIDI，完美解决密密麻麻乱音。

  一句话总结

  Melodyne 把人声当"连续的线条"来理解(按乐句/力度切分,保留渐弱尾音,音高稳定);basic_pitch 把人声当"一串离散音高事件"来检测(按音高抖动切分,丢尾音,起音易误判邻音)。

  所以 basic_pitch 的 37 音比 Melodyne 的 32 音多,多的不是"细节",而是把同一个长音抖碎成的幻音。这也解释了为什么 basic_pitch"音域对、分布对,但听起来还是不如 Melodyne
  像"--它缺的是对人声连贯性的理解,不是音高识别能力。

  这个发现其实指向一个改进方向:basic_pitch 如果加一步"相邻短音 + 音高相近 + 力度递减 -> 合并"的后处理,就能逼近 Melodyne 的连贯感。

## 五、快速避坑总结
1. 别用audio-convert这类杂牌在线转换器，模型落后必乱；
2. 转换前必须提取**无伴奏、少混响纯人声干声**；
3. 人声天生多滑音颤音，任何工具都会产生少量碎音，导出MIDI后一定要进DAW手动清理短音符；
4. 想要零乱音最优路线：UVR5分人声 → Melodyne提取MIDI。

## 六、本项目实现（wav_mid_human 技能）

本文档的方案3（CREPE/pYIN脚本+合并碎音）已落地为 wav_mid_human 技能。
