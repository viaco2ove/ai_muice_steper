# MuseScore 原生工程格式
## 1. `.mscz`（日常默认工程文件）
- **标准保存格式**，你平时写谱直接保存生成的文件
- 本质：ZIP压缩包，内部包含 `score.mscx` + 嵌入图片、自定义素材、音色配置等
- 优点：体积小、完整保存所有排版/音符/歌词/混音参数，**唯一推荐日常使用**
- 仅MuseScore能完整编辑，其他制谱软件打不开

## 2. `.mscx`（无压缩XML源码工程）
- 纯XML文本文件，无压缩，可记事本/代码编辑器打开查看乐谱底层代码
- 用途：版本控制、手动修改乐谱参数、调试脚本、批量处理乐谱
- 缺点：文件体积大，不适合普通编曲存稿

## 补充相关格式（非原生工程，仅交换用）
1. `.mxl` / `.xml`：通用乐谱交换格式（MusicXML），Sibelius、Finale、Guitar Pro互通，但会丢失MuseScore专属排版、音色设置
2. `.mid` / `.midi`：MIDI音符文件，只存音高节奏，丢失谱面符号、歌词、强弱标记
3. 备份文件：`.mscz,` / `.mscx,` 软件自动生成的临时备份稿

## 简单区分
- 做歌、存谱、分享工程 → **mscz**
- 写脚本、批量修改乐谱源码 → **mscx**

## 二、导出音频能不能直接发布？分两层判断
### 1. MuseScore软件本身不限制你的作品版权

**能不能发，只看两点：音源版权 + 原曲版权**
#### 情况A：原创旋律，无翻唱，使用合规音源

哪怕音源免费，**旋律歌词属于原作者**，直接上传平台会判定侵权下架、限流、索赔；商用盈利必须获得词曲版权方授权。
#### 情况C：第三方音源是CC-NC（禁止商用）
仅个人听歌自娱，不能发布到平台、不能接商单、不能变现。

### 补充：导出音频成品质量建议
- 基础GM音源：不建议直接发布，混音单薄、电子感强；
- MuseSounds免费库 / 自制人声sf2：导出44.1kHz WAV，再简单混音后可直接上线；
- 专业商用配乐：建议导出WAV导入FL Studio等DAW二次混音优化。
